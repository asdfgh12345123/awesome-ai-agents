# Contributing

Thank you for your interest in contributing!

## How to Contribute
1. Fork this repository
2. Add your resource to the appropriate table
3. Submit a pull request

## Guidelines
- Resource must be actively maintained
- Include a working link
- Add a brief description
- Place in the correct category

## Categories
- Frameworks
- Multi-Agent Systems
- Coding Agents
- Research Agents
- Web Agents
- Autonomous Agents
- Agent Memory
- Agent Tools
